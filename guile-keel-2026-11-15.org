# guile-keel

A Guile 3 host for [forth-keel](https://github.com/aygp-dr/forth-keel): the
13 keel primitives and an inner interpreter in Scheme, and the frames layer
(Forth layer 0) in Forth, built from those primitives only.

| Layer | File | Size |
|-------|------|------|
| cell arithmetic (32-bit) | `src/keel/cell.scm` | 36 lines |
| memory, stacks, inner interpreter | `src/keel/vm.scm` | 165 lines |
| dictionary, bootstrap words, outer interpreter | `src/keel/outer.scm` | 202 lines |
| frames: 151 Forth definitions | `forth/frames.fs` | 193 lines |

Results on this host (Guile 3.0.9, x86_64):

- forth-keel sea-trials layer 0: **22/22**, about 6 s for the whole suite.
- `tests/frames-check.fs`: output identical to gforth 0.7.3 (57 lines of
  arithmetic, comparison, division, output, loop and defining-word cases).
- Layer x (strings `compare`, `catch`/`throw`, floats, `allocate`, locals): 0/7,
  as expected; these wordsets are outside the layered build.

## Build order

Each step was tested before the next one started.

```mermaid
flowchart LR
  C["1 cell arithmetic<br/>+ nand 0= um* um/mod<br/>on 32-bit values"] --> M["2 memory<br/>64 KiB bytevector,<br/>@ ! little-endian"]
  M --> V["3 inner interpreter<br/>stacks in memory,<br/>indirect threading, NEXT"]
  V --> O["4 outer interpreter<br/>parse, find, number,<br/>: ; create does> '"]
  O --> F["5 frames.fs<br/>Forth from primitives"]
  F --> T["6 sea-trials<br/>layer 0"]
```

The 32-bit arithmetic comes first because every later layer assumes it:
`+` must wrap at 2^32, `um*` must return a 64-bit product as two cells, and
`um/mod` must reject a quotient that does not fit. `tests/cell-test.scm`
checks each primitive against exact integer arithmetic on edge values and
random values before any memory or interpreter code exists.

## The keel

Primitives (exactly the forth-keel R-K-01 list):

| Word | Stack | Code |
|------|-------|------|
| `@` | `( addr -- x )` | 16 |
| `!` | `( x addr -- )` | 17 |
| `sp@` | `( -- addr )` address of the top data-stack item | 18 |
| `rp@` | `( -- addr )` address of the top return-stack item | 19 |
| `0=` | `( x -- f )` | 20 |
| `+` | `( a b -- a+b )` mod 2^32 | 21 |
| `nand` | `( a b -- ~(a&b) )` | 22 |
| `exit` | `( -- ) ( R: a -- )` | 23 |
| `key` | `( -- c )` -1 at end of input | 24 |
| `emit` | `( c -- )` | 25 |
| `execute` | `( xt -- )` | 26 |
| `um*` | `( u1 u2 -- lo hi )` | 27 |
| `um/mod` | `( lo hi u -- rem quot )` | 28 |

Bootstrap words supplied by the host, because they parse input or lay down
headers (sectorforth makes the same split): `:` `;` `create` `does>` `'`, the
comment syntax `\` and `(`, and the constants `state >in #tib dp latest base
tib s0`. Code numbers 0-4 are the inner interpreter's own: ENTER, DOVAR,
DOCON, HALT, DODOES.

```mermaid
flowchart TD
  F["fetch: w = mem[ip], ip += 4"] --> D{"code = mem[w]"}
  D -->|"0 ENTER"| E["rpush ip, ip = w+4"]
  D -->|"1 DOVAR"| VAR["push w+8"]
  D -->|"2 DOCON"| CON["push mem[w+4]"]
  D -->|"4 DODOES"| DOES["push w+8, rpush ip, ip = mem[w+4]"]
  D -->|"16-28 primitive"| P["run primitive"]
  D -->|"32-36 host word"| H["run host word"]
  D -->|"3 HALT"| X["return to the outer interpreter"]
  E --> F
  VAR --> F
  CON --> F
  DOES --> F
  P --> F
  H --> F
```

Memory map (byte addresses, 64 KiB):

| Range | Use |
|-------|-----|
| `0x0000-0x003F` | system variables: state, >in, #tib, dp, latest, base, scratch thread |
| `0x0040-0x023F` | terminal input buffer (512 bytes) |
| `0x0400-0x7FFF` | dictionary (frames use about 7.5 KiB) |
| `0x8000-0xDFFF` | heap, reserved for planking's two semispaces |
| `0xE000-0xEFFF` | data stack, grows down from `0xF000` |
| `0xF000-0xFFFF` | return stack, grows down from `0x10000` |

Header: link cell, flags/length byte (bit 7 immediate, bit 6 hidden), name,
padding to a cell, then the code field (the xt).

## How frames.fs bootstraps

1. **No literals yet.** `dup` is `sp@ @`; `(-1)` and `(1)` are built from
   `nand` and `+`; `(cell)` is `sp@ sp@ -`. These words are slow because each
   use re-derives its constants.
2. **Constants.** `(constant)` uses `create` and then writes the DOCON code
   into the new word's code field, so `-1 0 1 cell 3cells` each cost one
   step.
3. **Fast core.** `lit`, `-`, `over`, `swap` and the rest are redefined on top
   of the constants. `lit` reads the cell after its call site through `rp@`
   and moves the return address past it.
4. **Return stack.** `>r` and `r>` rewrite return addresses with `rp@` and
   `!`, as in sectorforth. `drop` is `sp@ !` (store the top item into its own
   slot), because sectorforth's `dup - +` needs a second item below and this
   keel checks for underflow.
5. **Everything else** (control flow, division, output, parsing, `do` loops
   with `leave`, `case`, `defer`, `value`/`to`) is ordinary Forth on top.

Step 2 exists because of a measurement: with only the slow words,
`220-sicp-1.2.2-fib` needed more than 200 million steps and 15 s; after the
constants it takes 1.5 s.

## Usage

```sh
make            # build, unit tests (cell, vm, outer), differential test vs gforth
make trials     # forth-keel sea-trials layer 0 (FORTH_KEEL=../../aygp-dr/forth-keel)
bin/keel file.fs            # load frames.fs, then file.fs
bin/keel -e '10 0 do i . loop'   # error: do outside a definition, as in gforth
bin/keel --bare -e '3 4 + 48 + emit'   # primitives only, no frames.fs
```

`KEEL_STEPS` sets the instruction budget per top-level word (default 200
million); exceeding it is an error rather than a hang.

## Known differences from gforth

- Reading below an empty stack with `dup` or `over` is not detected:
  both are memory reads (`sp@ @`), not pops. gforth reports a stack underflow.
- `do`, `if` and the other control words are immediate everywhere, without
  gforth's interpret-state warnings.
- Error messages are `keel: FILE:LINE: message` and stop the file.
- Cells are 32 bits; gforth on x86_64 has 64-bit cells.

** bin/keel

Command-line host: loads forth/frames.fs (unless --bare), then each file and each -e string. Must be executable.

#+begin_src scheme :tangle bin/keel :tangle-mode o755
#!/usr/bin/env -S guile --no-auto-compile -e main -s
!#
;;; keel [--bare] [-e CODE] FILE ...
;;; Load forth/frames.fs (unless --bare), then each FILE and each -e CODE in order.
;;; Exit 1 on the first error, printing it to stderr.
(define here-dir (dirname (dirname (current-filename))))
(set! %load-path (cons (string-append here-dir "/src") %load-path))
(set! %load-compiled-path (cons (string-append here-dir "/build") %load-compiled-path))
(use-modules (keel vm) (keel outer) (ice-9 match))

(define (main args)
  (set-port-encoding! (current-output-port) "ISO-8859-1")
  (let ((vm (make-keel)) (bare #f) (status 0))
    (define (do-it thunk)
      (catch 'keel-error thunk
        (lambda (key msg)
          (force-output (current-output-port))
          (format (current-error-port) "keel: ~a~%" msg)
          (exit 1))))
    (let loop ((as (cdr args)) (actions '()))
      (match as
        (("--bare" . rest) (set! bare #t) (loop rest actions))
        (("-e" code . rest) (loop rest (cons (lambda () (interpret-string! vm code)) actions)))
        ((file . rest) (loop rest (cons (lambda () (load-file! vm file)) actions)))
        (()
         (unless bare (do-it (lambda () (load-file! vm (string-append here-dir "/forth/frames.fs")))))
         (for-each do-it (reverse actions)))))
    (force-output (current-output-port))
    (exit status)))
#+end_src

Module (keel cell): 32-bit cell arithmetic for + nand 0= um* um/mod. Built and tested first.

#+begin_src scheme :tangle src/keel/cell.scm
;;; (keel cell) -- 32-bit cell arithmetic for the keel primitives.
;;; Every cell is held as an exact integer in [0, 2^32). Signed views are
;;; computed only where a primitive needs them.
(define-module (keel cell)
  #:export (cell-bytes cell-mask u32 s32 true-flag
            cell+ cell-nand cell-0= cell-um* cell-um/mod))

(define cell-bytes 4)
(define cell-mask #xFFFFFFFF)
(define true-flag cell-mask)            ; Forth true: all bits set

(define (u32 n) (logand n cell-mask))
(define (s32 n)
  (let ((u (u32 n)))
    (if (>= u #x80000000) (- u #x100000000) u)))

;; +    ( n1 n2 -- n3 )      sum modulo 2^32
(define (cell+ a b) (u32 (+ a b)))
;; nand ( x1 x2 -- x3 )      bitwise not-and
(define (cell-nand a b) (u32 (lognot (logand a b))))
;; 0=   ( x -- flag )        true if x is zero
(define (cell-0= a) (if (zero? (u32 a)) true-flag 0))
;; um*  ( u1 u2 -- ud )      unsigned 32x32 -> 64 product, returned as (values lo hi)
(define (cell-um* a b)
  (let ((p (* (u32 a) (u32 b))))
    (values (u32 p) (u32 (ash p -32)))))
;; um/mod ( ud u -- urem uquot )  ud is (lo, hi); returned as (values rem quot)
(define (cell-um/mod lo hi d)
  (let ((ud (+ (u32 lo) (ash (u32 hi) 32)))
        (dd (u32 d)))
    (when (zero? dd)
      (throw 'keel-error "um/mod: division by zero"))
    (let ((q (quotient ud dd)))
      (when (> q cell-mask)
        (throw 'keel-error "um/mod: quotient does not fit in a cell"))
      (values (remainder ud dd) q))))
#+end_src

** src/keel/vm.scm

Module (keel vm): memory layout, code numbers, memory-resident stacks and the inner interpreter (run-xt!).

#+begin_src scheme :tangle src/keel/vm.scm
;;; (keel vm) -- memory, stacks and the inner interpreter.
;;;
;;; Memory is one 64 KiB little-endian bytevector. Both stacks live in it,
;;; so sp@ and rp@ return real addresses that @ and ! can use.
;;; Threading is indirect: a compiled cell holds an xt (the address of a
;;; code field); the code field holds a code number.
(define-module (keel vm)
  #:use-module (keel cell)
  #:use-module (rnrs bytevectors)
  #:use-module (srfi srfi-9)
  #:use-module (ice-9 format)
  #:export (;; layout
            mem-size a-state a->in a-#tib a-dp a-latest a-base a-scratch
            tib-start tib-size dict-start heap-start heap-end s-limit s0 r-limit r0
            ;; codes
            code-enter code-dovar code-docon code-halt code-dodoes
            primitive-codes host-codes
            ;; vm
            make-vm vm-mem vm-ip set-vm-ip! vm-sp set-vm-sp! vm-rp set-vm-rp!
            vm-in set-vm-in! vm-out set-vm-out! vm-host set-vm-host! vm-halt-xt set-vm-halt-xt!
            vm-steps set-vm-steps!
            mem@ mem! memc@ memc!
            push! pop! rpush! rpop! stack->list reset-stacks!
            run-xt!))

;;; ---- layout (byte addresses) -------------------------------------------
(define mem-size   #x10000)
(define a-state    0)       ; 0 = interpret, nonzero = compile
(define a->in      4)       ; offset of the next unparsed character in the TIB
(define a-#tib     8)       ; number of characters in the TIB
(define a-dp      12)       ; dictionary pointer (frames define: here = dp @)
(define a-latest  16)       ; header address of the newest definition
(define a-base    20)       ; number conversion radix
(define a-scratch 24)       ; 2 cells: thread used by run-xt!
(define tib-start 64)
(define tib-size  512)
(define dict-start 1024)
(define heap-start #x8000)  ; reserved for planking (two semispaces)
(define heap-end   #xE000)
(define s-limit    #xE000)  ; data stack: cells in [s-limit, s0), grows down
(define s0         #xF000)
(define r-limit    #xF000)  ; return stack: cells in [r-limit, r0), grows down
(define r0         #x10000)

;;; ---- code numbers ----------------------------------------------------------
(define code-enter  0)      ; colon definition: body at xt+4
(define code-dovar  1)      ; created word: push xt+8
(define code-docon  2)      ; constant: push cell at xt+4
(define code-halt   3)      ; stop run-xt!
(define code-dodoes 4)      ; created word after does>: push xt+8, run thread at mem[xt+4]

;; The 13 keel primitives, in spec order.
(define primitive-codes
  '(("@" . 16) ("!" . 17) ("sp@" . 18) ("rp@" . 19) ("0=" . 20) ("+" . 21)
    ("nand" . 22) ("exit" . 23) ("key" . 24) ("emit" . 25) ("execute" . 26)
    ("um*" . 27) ("um/mod" . 28)))

;; Bootstrap words that parse input or build headers. Implemented by the host.
(define host-codes
  '((":" . 32) (";" . 33) ("create" . 34) ("does>" . 35) ("'" . 36)))

;;; ---- the machine -------------------------------------------------------------
(define-record-type <vm>
  (%make-vm mem ip sp rp in out host halt-xt steps)
  vm?
  (mem vm-mem)
  (ip vm-ip set-vm-ip!)
  (sp vm-sp set-vm-sp!)
  (rp vm-rp set-vm-rp!)
  (in vm-in set-vm-in!)
  (out vm-out set-vm-out!)
  (host vm-host set-vm-host!)          ; (lambda (code vm) ...) for host-codes
  (halt-xt vm-halt-xt set-vm-halt-xt!)
  (steps vm-steps set-vm-steps!))      ; remaining instruction budget

(define (make-vm)
  (%make-vm (make-bytevector mem-size 0) 0 s0 r0
            (current-input-port) (current-output-port) #f 0 200000000))

(define (err fmt . args) (throw 'keel-error (apply format #f fmt args)))

;;; ---- memory -----------------------------------------------------------------
(define-inlinable (mem@ vm a)
  (unless (and (>= a 0) (<= (+ a 4) mem-size)) (err "@: address ~a out of range" a))
  (bytevector-u32-ref (vm-mem vm) a (endianness little)))
(define-inlinable (mem! vm a x)
  (unless (and (>= a 0) (<= (+ a 4) mem-size)) (err "!: address ~a out of range" a))
  (bytevector-u32-set! (vm-mem vm) a (u32 x) (endianness little)))
(define (memc@ vm a) (bytevector-u8-ref (vm-mem vm) a))
(define (memc! vm a c) (bytevector-u8-set! (vm-mem vm) a (logand c 255)))

;;; ---- stacks (memory-resident) -----------------------------------------------
(define-inlinable (push! vm x)
  (let ((sp (- (vm-sp vm) 4)))
    (when (< sp s-limit) (err "data stack overflow"))
    (mem! vm sp x)
    (set-vm-sp! vm sp)))
(define-inlinable (pop! vm)
  (let ((sp (vm-sp vm)))
    (when (>= sp s0) (err "data stack underflow"))
    (set-vm-sp! vm (+ sp 4))
    (mem@ vm sp)))
(define-inlinable (rpush! vm x)
  (let ((rp (- (vm-rp vm) 4)))
    (when (< rp r-limit) (err "return stack overflow"))
    (mem! vm rp x)
    (set-vm-rp! vm rp)))
(define-inlinable (rpop! vm)
  (let ((rp (vm-rp vm)))
    (when (>= rp r0) (err "return stack underflow"))
    (set-vm-rp! vm (+ rp 4))
    (mem@ vm rp)))

(define (stack->list vm)
  "Data stack, bottom first, as signed integers."
  (let loop ((a (- s0 4)) (acc '()))
    (if (< a (vm-sp vm)) (reverse acc) (loop (- a 4) (cons (s32 (mem@ vm a)) acc)))))

(define (reset-stacks! vm) (set-vm-sp! vm s0) (set-vm-rp! vm r0))

;;; ---- inner interpreter ------------------------------------------------------
;; Fetch the next xt from the thread and advance ip.
(define-inlinable (fetch! vm)
  (let ((ip (vm-ip vm)))
    (set-vm-ip! vm (+ ip 4))
    (mem@ vm ip)))

(define (run-xt! vm xt)
  "Execute XT and return when it finishes. The scratch thread holds the halt
word, so the outermost exit lands on it. The instruction budget is counted in
a local variable and written back when the run ends."
  (mem! vm a-scratch (vm-halt-xt vm))
  (set-vm-ip! vm a-scratch)
  (let loop ((w xt) (n (vm-steps vm)))
    (when (<= n 0) (set-vm-steps! vm 0) (err "step limit reached"))
    (case (mem@ vm w)
      ((0) (rpush! vm (vm-ip vm)) (set-vm-ip! vm (+ w 4)) (loop (fetch! vm) (- n 1)))   ; ENTER
      ((1) (push! vm (+ w 8)) (loop (fetch! vm) (- n 1)))                                 ; DOVAR
      ((2) (push! vm (mem@ vm (+ w 4))) (loop (fetch! vm) (- n 1)))                       ; DOCON
      ((3) (set-vm-steps! vm n))                                                          ; HALT
      ((4) (push! vm (+ w 8)) (rpush! vm (vm-ip vm))                                      ; DODOES
           (set-vm-ip! vm (mem@ vm (+ w 4))) (loop (fetch! vm) (- n 1)))
      ((16) (push! vm (mem@ vm (pop! vm))) (loop (fetch! vm) (- n 1)))                    ; @
      ((17) (let* ((a (pop! vm)) (x (pop! vm))) (mem! vm a x)) (loop (fetch! vm) (- n 1))) ; !
      ((18) (push! vm (vm-sp vm)) (loop (fetch! vm) (- n 1)))                             ; sp@
      ((19) (push! vm (vm-rp vm)) (loop (fetch! vm) (- n 1)))                             ; rp@
      ((20) (push! vm (cell-0= (pop! vm))) (loop (fetch! vm) (- n 1)))                    ; 0=
      ((21) (let* ((b (pop! vm)) (a (pop! vm))) (push! vm (cell+ a b))) (loop (fetch! vm) (- n 1)))     ; +
      ((22) (let* ((b (pop! vm)) (a (pop! vm))) (push! vm (cell-nand a b))) (loop (fetch! vm) (- n 1))) ; nand
      ((23) (set-vm-ip! vm (rpop! vm)) (loop (fetch! vm) (- n 1)))                        ; exit
      ((24) (let ((c (read-char (vm-in vm))))                                             ; key
              (push! vm (if (eof-object? c) cell-mask (char->integer c))))
            (loop (fetch! vm) (- n 1)))
      ((25) (write-char (integer->char (logand (pop! vm) 255)) (vm-out vm)) (loop (fetch! vm) (- n 1))) ; emit
      ((26) (loop (pop! vm) (- n 1)))                                                     ; execute
      ((27) (let* ((b (pop! vm)) (a (pop! vm)))                                           ; um*
              (call-with-values (lambda () (cell-um* a b))
                (lambda (lo hi) (push! vm lo) (push! vm hi))))
            (loop (fetch! vm) (- n 1)))
      ((28) (let* ((d (pop! vm)) (hi (pop! vm)) (lo (pop! vm)))                           ; um/mod
              (call-with-values (lambda () (cell-um/mod lo hi d))
                (lambda (r q) (push! vm r) (push! vm q))))
            (loop (fetch! vm) (- n 1)))
      ((32 33 34 35 36) ((vm-host vm) (mem@ vm w) vm) (loop (fetch! vm) (- n 1)))        ; host words
      (else (err "bad code ~a at xt ~a" (mem@ vm w) w)))))

(define flag-immediate 128)

(define (here vm) (mem@ vm a-dp))

(define (align a) (logand (+ a 3) (lognot 3)))

(define (header>xt vm h)
  (align (+ h 5 (logand (memc@ vm (+ h 4)) 31))))

(define (make-header! vm name code)
  "Lay down a header for NAME with CODE in its code field; return the header address."
  (let* ((name (string-downcase name))
         (n (string-length name))
         (h (align (here vm))))
    (when (> n 31) (err "name too long: ~a" name))
    (mem! vm h (mem@ vm a-latest))
    (memc! vm (+ h 4) n)

(define (string-for-each-index f s)
  (let loop ((i 0)) (when (< i (string-length s)) (f i) (loop (+ i 1)))))

(define (header-name vm h)
  (let ((n (logand (memc@ vm (+ h 4)) 31)))
    (list->string (map (lambda (i) (integer->char (memc@ vm (+ h 5 i)))) (iota n)))))

(define (find-word vm name)
  "Return (xt . immediate?) for the newest visible definition of NAME, or #f."
  (let ((name (string-downcase name)))
    (let loop ((h (mem@ vm a-latest)))
      (cond ((zero? h) #f)
            ((and (zero? (logand (memc@ vm (+ h 4)) flag-hidden))
                  (= (logand (memc@ vm (+ h 4)) 31) (string-length name))
                  (string=? (header-name vm h) name))
             (cons (header>xt vm h) (not (zero? (logand (memc@ vm (+ h 4)) flag-immediate)))))
            (else (loop (mem@ vm h)))))))

;;; ---- parsing from the TIB in memory ---------------------------------------
(define (tib-char vm i) (integer->char (memc@ vm (+ tib-start i))))

(define (parse-name! vm)
  "Skip spaces, return the next space-delimited token (or \"\"), leave >in after its delimiter."
  (let ((n (mem@ vm a-#tib)))
    (let skip ((i (mem@ vm a->in)))
      (if (and (< i n) (char-whitespace? (tib-char vm i)))
          (skip (+ i 1))
          (let scan ((j i))
            (if (and (< j n) (not (char-whitespace? (tib-char vm j))))
                (scan (+ j 1))
                (begin
                  (mem! vm a->in (min n (+ j 1)))
                  (list->string (map (lambda (k) (tib-char vm k)) (iota (- j i) i))))))))))

(define (skip-past! vm ch)
  (let ((n (mem@ vm a-#tib)))
    (let loop ((i (mem@ vm a->in)))
      (cond ((>= i n) (mem! vm a->in n))
            ((char=? (tib-char vm i) ch) (mem! vm a->in (+ i 1)))
            (else (loop (+ i 1)))))))

(define (parse-number vm s)
  "Signed integer in the current base, as a cell, or #f."
  (let* ((base (mem@ vm a-base))
         (neg (and (> (string-length s) 1) (char=? (string-ref s 0) #\-)))
         (digits (if neg (substring s 1) s)))
    (and (> (string-length digits) 0)
         (let loop ((cs (string->list digits)) (acc 0))
           (if (null? cs)
               (u32 (if neg (- acc) acc))
               (let* ((c (char-downcase (car cs)))
                      (d (cond ((char-numeric? c) (- (char->integer c) 48))
                               ((char-alphabetic? c) (+ 10 (- (char->integer c) 97)))
                               (else 99))))
                 (and (< d base) (loop (cdr cs) (+ (* acc base) d)))))))))

            (mem! vm xt code-dodoes)

                 (w (find-word vm name)))

(define (make-keel)
  (let ((vm (make-vm)))
    (set-vm-host! vm host-word)
    (mem! vm a-dp dict-start)
    (mem! vm a-latest 0)
    (mem! vm a-base 10)
    (mem! vm a-state 0)
    (for-each (lambda (p) (make-header! vm (car p) (cdr p))) primitive-codes)
    (for-each (lambda (p) (make-header! vm (car p) (cdr p))) host-codes)
    (let ((semi (find-word vm ";")))                    ; ; is immediate
      (let loop ((h (mem@ vm a-latest)))
        (if (= (header>xt vm h) (car semi))
            (memc! vm (+ h 4) (logior (memc@ vm (+ h 4)) flag-immediate))
            (loop (mem@ vm h)))))
    (for-each (lambda (p)                                ; system constants
                (make-header! vm (car p) code-docon)
                (comma! vm (cdr p)))
              `(("state" . ,a-state) (">in" . ,a->in) ("#tib" . ,a-#tib) ("dp" . ,a-dp)
                ("latest" . ,a-latest) ("base" . ,a-base) ("tib" . ,tib-start) ("s0" . ,s0)
                ("heap-start" . ,heap-start) ("heap-end" . ,heap-end)))
    (let ((h (make-header! vm "(halt)" code-halt)))
      (memc! vm (+ h 4) (logior (memc@ vm (+ h 4)) flag-hidden))
      (set-vm-halt-xt! vm (header>xt vm h)))
    vm))

(define (interpret-line! vm line)
  (let ((n (min (string-length line) tib-size)))
    (string-for-each-index (lambda (i) (memc! vm (+ tib-start i) (char->integer (string-ref line i))))
                           (substring line 0 n))
    (mem! vm a-#tib n)
    (mem! vm a->in 0))
  (let loop ()
    (let ((tok (parse-name! vm)))
      (unless (string-null? tok)
        (cond
         ((string=? tok "\\") (mem! vm a->in (mem@ vm a-#tib)))
         ((string=? tok "(") (skip-past! vm #\)))
         ((find-word vm tok)
          => (lambda (w)
               (if (or (zero? (mem@ vm a-state)) (cdr w))
                   (begin (set-vm-steps! vm step-budget) (run-xt! vm (car w)))
                   (comma! vm (car w)))))
         ((parse-number vm tok)
          => (lambda (x)
               (if (zero? (mem@ vm a-state))
                   (push! vm x)
                   (let ((lit (find-word vm "lit")))
                     (unless lit (err "number ~a in a definition before lit is defined" tok))
                     (comma! vm (car lit))
                     (comma! vm x)))))
         (else (err "~a is undefined" tok)))
        (loop)))))

(define (interpret-string! vm s)
  (for-each (lambda (line) (interpret-line! vm line)) (string-split s #\newline)))

(define (load-file! vm path)
  "Interpret PATH line by line. On error, print it with the line number and rethrow."
  (call-with-input-file path
    (lambda (port)
      (set-port-encoding! port "ISO-8859-1")
      (let loop ((lineno 1))
        (let ((line (read-line port)))
          (unless (eof-object? line)
            (catch 'keel-error
              (lambda () (interpret-line! vm line))
              (lambda (key msg)
                (throw 'keel-error (format #f "~a:~a: ~a" path lineno msg))))
            (loop (+ lineno 1))))))))

SRFI-64 tests: each cell primitive against exact integer arithmetic, on edge values and seeded random values.

#+begin_src scheme :tangle tests/cell-test.scm
;;; Unit and property tests for (keel cell): each primitive against exact integer arithmetic.
(use-modules (keel cell) (srfi srfi-1) (srfi srfi-64) (ice-9 receive))
(test-runner-current (test-runner-simple))
(define rng (seed->random-state 20261115))
(define edges (list 0 1 2 3 #x7FFFFFFF #x80000000 #x80000001 #xFFFFFFFE #xFFFFFFFF #x10000 #xFFFF))
(define (rand-u32) (random #x100000000 rng))

(define (all-pairs xs) (append-map (lambda (a) (map (lambda (b) (cons a b)) xs)) xs))

(test-begin "cell")

(test-group "examples"
  (test-equal "+ wraps" 0 (cell+ #xFFFFFFFF 1))
  (test-equal "+ max+max" #xFFFFFFFE (cell+ #xFFFFFFFF #xFFFFFFFF))
  (test-equal "nand 0 0" #xFFFFFFFF (cell-nand 0 0))
  (test-equal "nand -1 -1" 0 (cell-nand #xFFFFFFFF #xFFFFFFFF))
  (test-equal "0= 0" true-flag (cell-0= 0))
  (test-equal "0= 1" 0 (cell-0= 1))
  (test-equal "s32 of max" -1 (s32 #xFFFFFFFF))
  (test-equal "s32 of min" -2147483648 (s32 #x80000000))
  (test-equal "u32 of -1" #xFFFFFFFF (u32 -1))
  (receive (lo hi) (cell-um* #xFFFFFFFF #xFFFFFFFF)
    (test-equal "um* lo" 1 lo)
    (test-equal "um* hi" #xFFFFFFFE hi))
  (receive (r q) (cell-um/mod 10 0 3)
    (test-equal "um/mod q" 3 q)
    (test-equal "um/mod r" 1 r))
  (receive (r q) (cell-um/mod 0 1 2)   ; 2^32 / 2
    (test-equal "um/mod 2^32/2" #x80000000 q))
  (test-error "um/mod by zero" 'keel-error (cell-um/mod 1 0 0))
  (test-error "um/mod overflow" 'keel-error (cell-um/mod 0 1 1)))

(define xs (samples 30))
(define ps (all-pairs xs))

(test-group "properties"
  (test-assert "+ is addition mod 2^32"
    (every (lambda (p) (= (cell+ (car p) (cdr p)) (modulo (+ (car p) (cdr p)) (expt 2 32)))) ps))
  (test-assert "+ is commutative"
    (every (lambda (p) (= (cell+ (car p) (cdr p)) (cell+ (cdr p) (car p)))) ps))
  (test-assert "nand is not-and"
    (every (lambda (p) (= (cell-nand (car p) (cdr p))
                          (- #xFFFFFFFF (logand (car p) (cdr p))))) ps))
  (test-assert "invert via nand: x nand x = ~x"
    (every (lambda (x) (= (cell-nand x x) (- #xFFFFFFFF x))) xs))
  (test-assert "0= only for zero"
    (every (lambda (x) (= (cell-0= x) (if (= x 0) #xFFFFFFFF 0))) xs))
  (test-assert "um* hi:lo equals exact product"
    (every (lambda (p) (receive (lo hi) (cell-um* (car p) (cdr p))
                         (= (+ lo (* hi (expt 2 32))) (* (car p) (cdr p))))) ps))
  (test-assert "um/mod: q*d + r = ud and r < d, for every ud = um* result"
    (every (lambda (p)
             (let ((d (if (zero? (cdr p)) 1 (cdr p))))
               (receive (lo hi) (cell-um* (car p) d)
                 (receive (r q) (cell-um/mod (cell+ lo 0) hi d)
                   (and (= (+ (* q d) r) (+ lo (* hi (expt 2 32)))) (< r d))))))
           ps)))

(define failed (test-runner-fail-count (test-runner-current)))
(test-end "cell")
(exit (if (zero? failed) 0 1))

#+begin_src scheme :tangle tests/vm-test.scm
;;; Tests for (keel vm): each primitive on hand-assembled threads, no frames.fs.
(use-modules (keel cell) (keel vm) (keel outer) (srfi srfi-1) (srfi srfi-64))

(define (xt vm name) (car (or (find-word vm name) (error "no word" name))))
(define (assemble! vm name . items)
  "Colon definition NAME whose body is ITEMS: strings are words, integers raw cells."
  (interpret-string! vm (string-append ": " name))
  (for-each (lambda (it) (comma! vm (if (string? it) (xt vm it) (u32 it)))) items)
  (interpret-string! vm ";")
  (xt vm name))
(define (run vm stack . items)
  "Push STACK (bottom first), run a fresh thread of ITEMS, return the stack."
  (reset-stacks! vm)
  (for-each (lambda (x) (push! vm x)) stack)
  (run-xt! vm (apply assemble! vm "t" items))
  (stack->list vm))
(define (fresh) (make-keel))

(test-begin "vm")

(test-equal "+ wraps" '(0) (run vm (list #xFFFFFFFF 1) "+"))

** tests/frames-diff.sh

Runs frames-check.fs on both systems and diffs the output. Must be executable.

#+begin_src sh :tangle tests/frames-diff.sh :tangle-mode o755
#!/usr/bin/env bash
# Run tests/frames-check.fs on gforth and on keel; the outputs must be identical.
set -u
cd "$(dirname "$0")/.."
expected=$(gforth tests/frames-check.fs -e bye 2>&1)
actual=$(bin/keel tests/frames-check.fs 2>&1)
if diff <(printf '%s\n' "$expected") <(printf '%s\n' "$actual") > /tmp/frames-diff.$$; then
  echo "PASS frames-diff ($(printf '%s\n' "$expected" | wc -l) lines identical to gforth)"; rm -f /tmp/frames-diff.$$
else
  echo "FAIL frames-diff"; head -20 /tmp/frames-diff.$$; rm -f /tmp/frames-diff.$$; exit 1
fi
#+end_src
